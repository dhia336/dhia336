# Software development projects

Projects spanning web applications, Android utilities, and embedded systems.

- **Backend:** Python, FastAPI, Node.js, Express, REST APIs
- **Frontend:** React, Vite, JavaScript, HTML, CSS
- **Languages:** Python, JavaScript, Java, PHP, SQL, C
- **Databases:** MySQL, PostgreSQL, MongoDB
- **Android and embedded:** Java, Android, BLE, ESP32-CAM, Arduino, HTTP, Wi-Fi
- **Tools and platforms:** Git, GitHub, Linux, Windows, Android Studio, Arduino IDE
